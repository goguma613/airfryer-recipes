# 🍟 에어프라이기 레시피 보관함

내가 가진 에어프라이기에 맞춰 레시피를 보관하고, 주방에서 폰으로 **조리를 진행**하며,
사용 기록이 쌓일수록 추천값이 정확해지는 **개인용 웹앱**입니다. 빌드·서버·계정 불필요.

## ⚠️ 가장 중요한 안전 안내
조리 온도/시간은 **"정확값"이 아니라 추정 시작점**입니다. 에어프라이어 조리시간은
두께·양·기기 구조에 따라 비선형으로 달라져 깔끔한 공식이 없습니다.
- **닭·돼지·다짐육·생선·달걀(위험식품)은 시간이 아니라 중심온도로 익힘을 판단하세요.**
  (가금류 74℃, 다짐육 71℃, 통살 63℃ — USDA 기준)
- 냉동 상태는 속까지 익는 데 더 오래 걸립니다. 항상 속까지 확인하세요.

## 핵심 기능
- **기기별 레시피 보관**: 내 에어프라이기를 등록하고 레시피마다 기준값 저장.
- **스마트 보정**: 다른 기기/다른 양으로 조리 시 시간을 추정해 **구간(예: 12~16분)**으로 제시.
  공식 = ① 전역 기본계수 → ② 기기별 보정 → ③ **이 기기에서 마지막 성공값** 우선.
- **조리 진행 도구**: 인앱 타이머 + 종료/단계 알림(진동·소리), 화면 꺼짐 방지(Wake Lock),
  큰 글씨 Cook Mode, "10분 후 뒤집기" 다단계 알림.
- **성공기록 학습**: 타이머 종료 시 👍딱좋음/🥶덜익음/🔥탐 + "다음엔 ±분"을 기록 → 다음 추천 반영.
- **빠른 입력**: 이름·온도·시간 3개만 필수. 봉지/사이트 텍스트 붙여넣기 → 온도·시간 자동추출. 레시피 복제.
- **백업**: JSON 내보내기/가져오기(가져오기 시 검증·되돌리기).

## 실행 방법
서비스워커/PWA는 `file://`에서 동작하지 않으므로 **http로 실행**하세요.

```bash
# 폴더에서
npx serve        # 또는
python -m http.server 8000
```
브라우저에서 `http://localhost:8000` 접속.

## 폰에서 쓰기 (PWA)
**배포 주소: https://goguma613.github.io/airfryer-recipes/**

폰 브라우저로 위 주소를 열고 **"홈 화면에 추가"** → 앱처럼 실행 + 오프라인 동작.

코드를 수정한 뒤에는 `git push`만 하면 GitHub Pages가 자동으로 다시 배포합니다.

> ⚠️ 데이터는 **이 브라우저에만** 저장됩니다(localStorage). 브라우저 데이터 삭제나
> 장기 미사용(특히 iOS Safari) 시 사라질 수 있어요. **주기적으로 설정 → 내보내기로 백업**하세요.

## 파일 구조
| 파일 | 역할 |
|---|---|
| `index.html` | 앱 셸 + 하단 탭 + 서비스워커 등록 |
| `style.css` | 모바일 우선·큰 버튼·고대비 스타일 |
| `store.js` | 상태 + localStorage + 마이그레이션 + import/export 검증 |
| `calc.js` | 보정 로직(**순수함수**, 테스트 대상) + 텍스트 추출 |
| `timer.js` | 조리 타이머 + 다단계 알림 + Wake Lock + 진동/비프 |
| `ui.js` | 렌더링(HTML 생성, XSS 방지) |
| `app.js` | 컨트롤러(네비게이션·이벤트·타이머 연결) |
| `manifest.json`, `sw.js` | PWA(홈 추가·오프라인, 버전드 캐시) |
| `tests.html` | `calc.js` 단위 테스트(브라우저로 열기) |

## 보정 계수 (calc.js 상단 `FACTORS`)
| 키 | 의미 | 기본값 |
|---|---|---|
| `amountExp` | 시간 ∝ (양 비)^지수 | 0.4 |
| `wattExp` | 시간 ∝ (기준W/대상W)^지수 (약한 축) | 0.7 |
| `ovenTempDrop` / `ovenTimeMult` | 오븐→에어프라이어 변환 | -20℃ / ×0.8 |
| `frozenExtra` | 냉동 안전 마진 | +25% |
| `rangeSpread` | 결과 구간 폭 | ±15% |

직접 돌려보고 잘 된 값을 "결과 기록"으로 남기면, 그 값이 다음 조리의 추천 기준이 됩니다.

## 테스트
